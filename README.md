# tullymander
In interactive tool to explore redistricting in Baltimore County


[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/fergalm/tullymander/HEAD)



Development Instructions:

* Develop on a branch, test your changes locally.
* Log out of the default user, and log into test user.
* Use nbgitpuller to install the branch

https://jupyterhub.github.io/nbgitpuller/link?hub=http://54.189.34.181&repo=https://github.com/fergalm/tullymander&branch=main&url=py/display.ipynb

(adjust the branch as appropriate)

* If the expected changes do not show on the server, restart the kernel, that usually fixes things.

* Once you have the feature complete 
    * Merge
    * Log out the test user
    * Log in as fergal2
    * Request the "main" version from github using the nbgitpuller url, changing the branch to main
    * Restart the kernel if necessary.
